Overtime record app

OPEN IT
- Any device: open index.html in a browser. Data saves on that device.

INSTALL AS AN APP (needs the folder hosted at an https address, e.g. GitHub Pages or any web server)
- Phone (Android/Chrome): open the address, menu > Add to Home screen.
- Phone (iPhone/Safari): open the address, Share > Add to Home Screen.
- Windows/Mac (Chrome or Edge): open the address, click the install icon in the address bar.
- Works offline after the first open.

SHARE WITH THE TEAM
- Each person enters their name, fills their month, taps "Share my month" and sends the file (WhatsApp/email).
- Whoever collects imports the files with "Import teammate file" to see the team table, then "Export month (CSV)".
